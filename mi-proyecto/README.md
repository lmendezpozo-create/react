# CURATED

## 🎯 ¿Qué problema resuelve?

Este proyecto resuelve la necesidad de presentar una tienda de muebles y diseño de forma moderna, clara y atractiva para clientes que buscan productos exclusivos para el hogar. En lugar de una simple galería, la aplicación ofrece una experiencia más completa: una landing page de bienvenida, una vista de productos, un área de contacto y un panel administrativo protegido para gestionar contenido o accesos.

La idea principal es crear una vitrina digital para una mueblería que transmita calidad, estilo y confianza, ayudando a los usuarios a explorar colecciones, conocer la marca y sentirse atraídos por una experiencia de compra elegante y funcional.

## 🛠️ ¿Cómo lo construiste?

Este proyecto fue desarrollado con React y Vite, utilizando React Router para la navegación entre páginas y Context API para manejar la autenticación del usuario. La estructura está organizada por componentes, páginas y datos para mantener un código limpio y fácil de mantener.

Entre las decisiones técnicas más importantes están:

- Uso de React para construir una interfaz dinámica y modular.
- React Router para navegar entre Inicio, Contacto, Login y Admin.
- Contexto de autenticación para simular un flujo de inicio de sesión y protección de rutas.
- Organización por carpetas como components, pages, context, data y styles para separar responsabilidades.
- Estilos propios para dar una identidad visual premium y moderna a la marca.

## 🚀 ¿Cómo se usa?

1. Clona el proyecto.
2. Entra a la carpeta del proyecto:
   ```bash
   cd mi-proyecto
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Ejecuta la aplicación en modo desarrollador:
   ```bash
   npm run dev
   ```
5. Abre la vista local que te indique Vite en el navegador.

Dentro de la app puedes:

- Explorar la página principal con la propuesta de la marca.
- Navegar a la sección de contacto.
- Iniciar sesión desde la página de Login.
- Acceder al panel administrativo si el usuario tiene permisos.

La IA me ayudó a estructurar mejor el proyecto, sugerir una organización de archivos clara y plantear una lógica de navegación y autenticación más ordenada. También me apoyó en la redacción del contenido de la marca y en la formulación de una descripción del proyecto más clara y profesional.
